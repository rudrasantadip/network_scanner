# Network Scanner

Network Scanner is a tool designed to scan networks, identify active hosts, and provide insights into connected devices. It helps users understand network activity, troubleshoot connectivity issues, and explore basic network discovery techniques.

## Key Features
- Discover active devices within a specified network.
- Identify reachable hosts and their IP addresses.
- Analyze network connectivity.
- Support network troubleshooting and diagnostics.
- Explore networking concepts and scanning techniques.

## Project Goal
To develop a practical network scanning utility that helps users understand network structure, identify active hosts, and learn the fundamentals of network administration and cybersecurity.

## Intended Use
This tool is intended for educational purposes, network diagnostics, and authorized network assessment. Only scan networks you own or have permission to test.
